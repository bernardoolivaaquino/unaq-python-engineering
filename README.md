# UNAQ Python Engineering Scripts

Collection of **Python** scripts and coursework developed across engineering fundamentals courses at **UNAQ**.

## Repository Structure
- **`programming/`** — Programming fundamentals assignments, matrix operations (`transpuesta.py`), and interactive scripts (`juego.py`).
- **`engineering-math/`** — Numerical methods and engineering mathematics scripts (*Matemáticas para Ingeniería 2*).
- **`mechanics-of-materials/`** — Python calculations for stress, strain, and mechanics of materials (*Resistencia de los Materiales*).

## Tools & Technologies
- **Python 3**
- Standard scientific/math libraries (`numpy`, `matplotlib`, etc. where applicable)
